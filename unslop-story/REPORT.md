## 2. 방향 5줄

| 줄 | 내용 |
|---|---|
| 제품 | 시민이 가까운 AED를 찾아 출입·점검 상태를 확인하고, 설치기관이 점검·복구를 기록하는 서비스 |
| 성격 | 침착하고, 정확하고, 급할 때 바로 읽히는 |
| 세계 | 공공건물 로비 벽의 AED 보관함과 비상 안내 표지. 무광 회색 함 위의 빨간 하트 |
| 모먼트 | 홈의 AED 보관함 그림, 지도, 추천 1순위 카드 |
| 시그니처 | '출입구 → 건물/층 → 보관함' 경로선. 마지막 칸만 빨갛게 표시하고 다른 곳에는 쓰지 않음 |

포인트 색은 세계의 '빨간 하트 표지'에서 가져온 #c62a22 하나입니다. 흰 글자 대비는 4.5:1 이상이고, 응급 버튼·주 버튼·선택된 탭 밑줄·보관함 칸에만 씁니다.

## 3. 9단계에서 바뀐 것

| 단계 | 바뀐 것 |
|---|---|
| 1. 간격 | 간격 값 339개를 4px 눈금에 맞춤. 대시보드 통계 카드 5+5, 머리글 탭·전환 버튼 높이 통일 |
| 2. 색 | 회색 계열 하나(#fafafa / #fff / #f4f4f5), 글자 3단계, 강조색 빨강 하나. 그라데이션·빛 번짐·색 그림자·유리 효과 제거, 모델 태그 무채색 |
| 3. 아이콘 | 이모지 168개 → 0개. Lucide 선 아이콘 33종을 파일에 내장(16px), 색은 글자색과 같음 |
| 4. 문구 | 홈 제목 "가까운 AED를 찾고, 생명을 살리는 순서를 익히세요." → "지금 열려 있고 점검된 AED를 가장 가까운 순서로 찾습니다", 느낌표·부제 마침표 제거, "STEP 1" → "1단계" |
| 5. 글씨 | Pretendard, 굵기 400~600, 대문자 라벨 0개, 자간 0, 숫자는 고정폭 |
| 6. 배치 | 홈 히어로를 글 · 보관함 그림 · 응급 블록 3칸으로 나눔. 관리자 머리글의 글자 깨짐 수정 |
| 7. 디테일 | 모서리 6~16px를 크기에 맞춤, 경로선 시그니처를 상세 화면·추천 카드·홈 판정 순서에 사용, 1순위 카드 강조 |
| 8. 그림 | 이미지 생성 도구가 없어 지침대로 코드로 그림: 로비 벽 AED 보관함(무광 회색 함, 유리문, 빨간 하트 표지, 초록 대기등) |
| 9. 움직임 | 무한 깜빡임·떠오름 제거. 색 변화와 누를 때 0.98배 축소만, 곡선 하나 `cubic-bezier(.22,1,.36,1)` |

## 4. 템플릿 검사

**부분 통과.** 제품 이름을 바꾸면 어울리지 않는 요소: 홈 제목, 보관함 그림, 판정 순서 경로선, 출입·기기 상태 배지, 응급 블록. 대시보드 숫자 카드 영역은 여전히 일반 관리 화면처럼 보입니다.

## 5. 한계

- 이미지 생성 도구를 연결하지 않아 보관함은 코드로 그린 그림입니다.
- 글꼴은 jsDelivr에서 불러오므로, 인터넷이 없으면 시스템 글꼴로 보입니다.
- 영상 속 통계 숫자는 시연 모드 화면 값(0·3·3)입니다.
- 각 화면을 한 번씩만 진행한 결과입니다.
